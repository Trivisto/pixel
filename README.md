# Pixel

QR code maker & scanner — a free web app by [Trivisto](https://trivisto.github.io).

**Open it:** https://trivisto.github.io/pixel/

- Make codes for links, text, Wi-Fi, contacts, email, calls and messages
- Style everything: dot shapes, corners, solid/gradient colors, background color/gradient/photo, a picture in the middle, a frame with a label
- Live check that the design still scans
- Scan with the camera or from a photo/screenshot
- Works offline. Nothing is uploaded.

**On iPhone:** open the link in Safari → Share → **Add to Home Screen**.

Plain HTML/JS, no build step. Uses [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) and [jsQR](https://github.com/cozmo/jsQR) (see `LICENSES.txt`). QR Code is a registered trademark of DENSO WAVE INCORPORATED.
